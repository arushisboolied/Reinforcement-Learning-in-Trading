## 2. NumPy 🔢

NumPy (Numerical Python) is one of the fundamental libraries for numerical computing in Python.

It provides efficient operations on arrays and matrices and is widely used in scientific computing, Machine Learning and AI.

We'll primarily use it for:

- Creating and manipulating arrays.
- Performing mathematical and logical operations.
- Working with matrices.
- Basic linear algebra operations.

## 4. Pandas 🐼

Pandas is a powerful Python library for working with structured datasets.

It provides two primary data structures:

- **Series:** A one-dimensional labelled data structure.
- **DataFrame:** A two-dimensional tabular data structure consisting of rows and columns.

We'll be using Pandas extensively when working with financial datasets, so getting comfortable with it is particularly important.

Some things worth exploring:

- Creating and manipulating DataFrames.
- Reading data from CSV files.
- Selecting and filtering rows and columns.
- Handling missing values.
- Basic data analysis and aggregation.

### Learning Resources

- [Pandas Official Documentation](https://pandas.pydata.org/)
- [W3Schools Pandas Tutorial](https://www.w3schools.com/python/pandas/default.asp)
- [Pandas — Video Tutorial](https://youtu.be/vmEHCJofslg?feature=shared)
